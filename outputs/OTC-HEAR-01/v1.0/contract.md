## 1. 执行纪律

1. **冻结**：执行前对本文件和 `config.yaml` 记 sha256。看过任何结局数字后，不改人群、窗口、阈值、对照或子集。
2. **数据**：只用 NCHS 官方 NHIS 公共使用文件（公有领域，无需签字、无需注册）。允许 Codex 直接下载和处理个体级记录，无需用户本机运行。遵守 NHIS 数据使用限制：不尝试识别个人，不与其他数据联结。
3. **独立单位**：样本成人（sample adult）。所有 N 报告未加权人数；所有率报告加权估计，并用设计校正的标准误。
4. **语义**：程序或数据问题记 `NOT_RUN` / `NO_VALID_RESULT`，不写成阴性。
5. **禁止救题**：任一门 STOP 后，不换年龄下限、换窗口或换结局来"通过"。
6. **工程错误**（读文件、变量名、编码）在同一版本内修复并记录，不升版本。
7. **不登录任何门户，不依赖作者或数据方回信。**
8. **失败分层报告**：工程｜数据可执行性｜测量/构念｜科学结果｜增量不足。

## 2. 冻结对象

| 项目 | 冻结定义 |
|---|---|
| 政策时点 | FDA OTC 助听器规则 2022-10-17 生效 |
| 人群 | 样本成人，年龄 ≥50 岁 |
| 听力问题人群 H | `HEARAID_A`=1（使用助听器）**或** `HEARINGDF_A` ∈ {有些困难, 很困难, 完全听不见}。说明：该困难题问的是"即使使用助听器"时的困难，所以单用困难题定义的人群会被治疗本身改变；H 取并集，在助听器使用上是封闭的 |
| 主结局 | `HEARAID_A`=1 的加权比例（H 内） |
| 前期 | 2019、2021、2022 年 1–9 月（排除 2020 全年：疫情期电话访问、样本结构异常） |
| 过渡期 | 2022 年 10–12 月，排除 |
| 后期（主） | 2023–2024（纯 OTC 设备时期） |
| 后期（扩展） | 2025（同时含耳机式助听功能：FDA 于 2024-09 授权，单独报告，不并入主估计） |
| 主估计量 | 年龄×性别标准化后的使用率差 Δ = 后期 − 前期，单位为百分点。标准化以 2019–2024 合并的 H 分布为标准（50–64、65–74、75–84、85+ × 性别） |
| 等效界 | ±2.5 个百分点 |
| 回退规则 | 若公共文件没有访谈季度/月份变量，前期改为 2019 和 2021，整年剔除 2022；这是预设回退，不算偏离 |

## 3. 竞争解释 → 区分分析

| 竞争解释 | 区分分析（L3/L4） | 预测模式 |
|---|---|---|
| 疫情期听力服务中断后的反弹 | 阴性对照结局：50+ 成人眼镜/隐形眼镜使用率（同样依赖线下验配、同样受疫情冲击，但不受 OTC 规则影响）；逐年事件图 | OTC 效应：听力有跳变，眼镜无跳变 |
| 长期上升趋势（技术进步、队列更愿意戴） | 以前期斜率外推作敏感性；年龄梯度 | OTC 购买者偏年轻，预测 50–69 岁的变化 ≥ 80 岁及以上 |
| Medicare Advantage 听力福利扩张 | 65+ Medicare 人群按 MA 与传统 Medicare 分层（变量存在时） | OTC 降低的是自付门槛，预测传统 Medicare 的变化 ≥ MA |
| H 分母变化（宣传增加了自报困难） | 报告 H 本身的患病率前后变化；无分母的结局：全体 50+ 成人中助听器使用率 | 两种口径同向 |
| 访问方式/权重变化 | 访问方式指示变量存在时作敏感性；阴性对照结局 | 眼镜无同期跳变 |
| 本来就有免费助听器的人群 | VA/TRICARE 覆盖者单列（描述性，功效低，不作判定） | 这部分人的变化应接近 0 |

## 4. 数据清单与桌面预检结果

**来源**：NCHS NHIS 2019–2025 Sample Adult 公共使用文件、对应年份的 imputed income 文件、codebook 和 summary/description 文档。2025 年公共文件已于 2026-09 发布。

### 4.1 Claude 桌面预检（交接前已完成）

| 项目 | 结果 | 依据 |
|---|---|---|
| 助听器使用题每年都在 | 通过（2019–2024），2025 年 `UNVERIFIED` | IPUMS 显示 2019–2024 年都问了"是否使用助听器"；OMB 2024–2026 年度核心大纲列有"Use of hearing aid" |
| 使用频率题 | 通过（2019–2024） | IPUMS HRAFREQ，问题 ID HEA.0020.00.1 |
| 眼镜题（阴性对照） | 通过（2019–2024），2025 年 `UNVERIFIED` | IPUMS GLASSLENS；OMB 大纲列有"Use of eyeglasses or contact lenses" |
| 校准目标 | 已定位 | NCHS Data Brief 414（2019）及其数据表 PDF |
| 访问条款/AI 处理 | 通过 | 公有领域公共文件 |
| 人数余量 | 估计通过 | 2021 年全年龄 H 未加权约 5,088 人（1,489 名使用者 + 3,599 名潜在使用者）。按此推算，50+ 每期远超门槛的 1.5 倍 |
| 查重 | 暂判 `ADJACENT`，待 A0 复核 | 见 §5 A0 |
| 访谈季度变量 | `UNVERIFIED` | 由 D 门核 |
| MA 指示变量、VA/TRICARE 变量 | `UNVERIFIED` | 由 D 门核；缺失时对应分析记 `NOT_RUN`，不判停 |
| 收入（贫困比）及多重插补文件 | `UNVERIFIED` | 由 D 门核 |

### 4.2 D 门需逐年核对的变量

每一年（2019、2020、2021、2022、2023、2024、2025）都要核对以下四项，并写入 `D/variable_audit.csv`：

- 题目原文是否一致；
- universe 是否一致；
- 编码是否一致；
- 未插补的有效 N。

变量名以 NCHS codebook 为准，括号内是预期名：

- 助听器使用（`HEARAID_A`）
- 听力困难（`HEARINGDF_A`）：须确认问的是全体样本成人，不是只问使用者
- 使用频率（`HEARAIDFR_A`）
- 眼镜/隐形眼镜使用
- 年龄（`AGEP_A`）、性别（`SEX_A`）
- 种族/族裔
- 教育
- 家庭收入贫困比，及 imputed income 文件的联结键与插补份数
- 保险：Medicare、Medicare Advantage、Medicaid、私人保险、TRICARE、VA
- 代答指示
- 访谈季度/月份
- 访问方式（若公共文件有）
- 设计变量：`WTFA_A`、`PSTRAT`、`PPSU`

另需从 NCHS 文档中摘录多年合并时的权重处理与方差估计规则，附原文页码。

## 5. 分层任务（每层 PASS 后才启动下一层）

### A0：查重复核（桌面，≤2 小时）

- **EXACT**：用 NHIS（或其他概率抽样的全国调查，如 NHATS、MCBS）估计 OTC 生效前后助听器使用率变化的论文、预印本或会议摘要。
- **PARENT**：已发表研究覆盖了 2023 年及以后的 NHIS 助听器使用趋势，并把它解读为 OTC 的影响。
- 必查：
  - PubMed、medRxiv/SSRN（近 24 个月）；
  - Razura 2025（Otolaryngol Head Neck Surg，NHIS 保险×助听器）：核实其年份范围，以及是否报告了 2023 年后的变化；
  - Johns Hopkins 的 NHATS 听力组（Reed、Nieman 等）2024–2026 的论文和摘要；
  - Picou & Huang 的 MarkeTrak 2025 分析（行业在线固定样本，预判为 ADJACENT）；
  - NCHS 自己的 data brief 或 NHIS Early Release 有无助听器趋势。
- **判定**：EXACT 或 PARENT → `STOP_DUP`；ADJACENT 或 NONE → PASS，写出最近研究与本研究的增量。

### D：文档语义门（≤3 小时）

**STOP_DATA 条件**（任一项触发即停）：
- 在 2019、2021、2022、2023、2024 中任一年，助听器使用题或听力困难题缺失，或题目原文/universe/编码有实质改变；
- 权重或设计变量缺失；
- 50+ 年龄无法识别。

**不判停、按预设处理的情形**：
- 季度缺失 → 走 §2 的回退规则；
- 2025 年缺题 → 扩展窗口记 `NOT_RUN`；
- MA 或 VA 变量缺失 → 对应分析记 `NOT_RUN`；
- 眼镜题缺失 → 阴性对照记 `NOT_RUN`，并在主结论表中降一级。

### L0：人数门（只计数，不计算结局比例，≤1 小时）

| 门 | 阈值 | 预估 |
|---|---|---|
| H(50+) 前期未加权 N | ≥6,000 | 约 10,000+ |
| H(50+) 后期（2023–24）未加权 N | ≥5,000 | 约 8,000 |
| H(50+) 中贫困比 <200% 者，每期 | ≥1,000 | 约 2,000+ |

任一门不达标 → `STOP_N`。

### L1：校准（≤2 小时）

用本流程复现 NCHS Data Brief 414 中 2019 年的数字：
- 45+ 助听器使用率（总体）；
- 65+ 助听器使用率（总体、男、女）；
- 18+ 有些困难率、很困难或听不见率。

逐项从 `db414-tables-508.pdf` 摘取点估计和 95% CI。注意：45+ 与 65+ 是不同的行，不要混用。

- **PASS**：所有点估计都落在原文 95% CI 内。
- **否则**：`CALIBRATION_FAIL`，先修流程。不允许改目标或改容差。

### L2：主分析（≤3 小时）

- **主估计量 Δ**：按 §2 定义。用设计加权线性概率模型，含时期指示和年龄×性别；报告 Δ 及 95% CI。
- **逐年事件图**：2019、2020（仅展示）、2021、2022 前三季度、2023、2024、2025 的标准化使用率。
- **结果到结论**（冻结）：

| Δ 的 95% CI | 结论 |
|---|---|
| 完全落在 (−2.5, +2.5) | 全国层面无有意义变化（等效成立） |
| 下限 > +2.5 | 有意义上升 |
| 下限 > 0 但跨过 +2.5 | 上升，但幅度可能小于有意义阈值 |
| 其他 | 不确定，报告可排除的最大幅度 |

### L3：竞争解释（≤3 小时）

按 §3 逐项执行。冻结判读：
- 阴性对照（眼镜）的 Δ 与助听器 Δ 同向，且 |Δ眼镜| ≥ 0.5×|Δ助听器| → 主结果的政策时期解释降级为"与全面服务反弹无法区分"；
- 无分母口径与主口径方向相反 → 主结果标记为"分母敏感"。

### L4：次要分析（≤3 小时）

1. **收入差距**：贫困比 <200% 与 ≥400% 两组的 Δ 之差（差中差），收入按多重插补合并。预设关注方向：差距缩小。
2. **年龄梯度**：50–69 岁对比 80 岁及以上。
3. **使用频率**：使用者中"一直使用"的比例，前后对比。预设方向：OTC 稀释使下降。
4. **2025 年扩展窗口**。
5. **MA 与传统 Medicare**、**VA/TRICARE**：描述性。

L4 结束即终局。

## 7. 已知风险（执行前告知）

- A0 有被 Johns Hopkins NHATS 组或 Razura 后续工作抢先的可能。这是本题最主要的风险。
- 2025 年文件是新发布的，变量名可能有改动，在 D 门逐年核对。
- 听力困难题问的是"即使使用助听器"时的困难，H 已按并集定义处理；不要用困难分级作为处理组/对照组。
- 主分析预计功效：前期约 1 万人、后期约 8 千人时，Δ 的 95% CI 半宽约 1.5 个百分点，能区分 ±2.5 的等效界。收入差中差的最小可检出差约 5 个百分点，只作次要分析。
- 2020 年排除是预设，不是看结果后的选择。
